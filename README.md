# Will Hammond, photography

The source for https://willhammondhimself.github.io/photography/, a static photography
portfolio built with Astro. The design spec lives in `docs/DESIGN.md`; if the code and the
spec disagree, the spec wins.

Pages: Index (the curated edit), Series, Archive (every photo, filterable), a viewer page
per photo at `/photo/<id>/`, and Info.

## Run it locally

Node 22.23 or newer is required. On this machine Node is not on the default PATH, so put
it there first:

```sh
export PATH=$HOME/.local/node/bin:$PATH
npm install
npm run dev        # http://localhost:4321/photography/
```

For a production check:

```sh
npm run build      # also regenerates src/data/photos.meta.json
npm run preview    # http://localhost:4321/photography/
```

## Add or replace a photo

1. In Lightroom, export the photo as JPEG, quality 90, sRGB, 3200 px on the long edge,
   with metadata included (the camera, lens, exposure and capture date are read from it;
   GPS is never read).
2. Save it as `src/assets/photos/<category>/<id>.jpg`. The id is lowercase words joined
   by hyphens, for example `half-dome-sentinel-bridge`. Categories: `yosemite`, `hawaii`,
   `greece`, `climbing`, `landscape`, `portraits`, `events`, `travel`. To replace a photo,
   overwrite the file and keep the id.
3. Add an entry to `src/data/photos.json`:

   ```json
   {
     "id": "half-dome-sentinel-bridge",
     "file": "yosemite/half-dome-sentinel-bridge.jpg",
     "title": "Half Dome from Sentinel Bridge",
     "place": "Yosemite Valley",
     "category": "yosemite",
     "series": "yosemite",
     "alt": "Half Dome lit pink at dusk above the Merced River, snow on the banks."
   }
   ```

   `series` is a series slug or `null`. Alt text must be under 160 characters and must
   not start with "Image of" or "Photo of". An optional `"focus": [50, 40]` sets the crop
   point for the phone-size Index opener.
4. If the photo belongs to a series, add it to that series' `plates` in
   `src/data/series.json`. To put it in the Index edit, add it to `src/data/index.json`.
   Plate types are `full`, `wide`, `left`, `right`, `center` and `pair` (see
   `docs/DESIGN.md` section 4.3).
5. Run `npm run build`. It refreshes `src/data/photos.meta.json` (size, dominant color,
   blur placeholder, EXIF) and checks the data. The build stops with a clear message if
   something is wrong, such as a missing file, a photo listed in a series it is not part
   of, or a `full` plate that is not a wide landscape.

Commit the new JPEG, the edited JSON files and the regenerated `photos.meta.json`
together.

Note: the current `src/data/*.json` files were generated by `.local-tools/build_data.py`
from Lightroom previews, which carry no EXIF. Once real exports are in place, edit the
JSON by hand as described above.

## Deployment

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site with
`withastro/action` and publishes `dist/` with `actions/deploy-pages`. In the repository
settings, under Pages, set the source to "GitHub Actions". The first build takes a few
minutes because every photo is encoded to AVIF and WebP at several widths; later builds
reuse the cached images.
